# Icons for mihomo

Icon assets for mihomo-related configuration and UI use.

## Flags

The current flag icons are derived from [FlagCDN](https://flagcdn.com/) SVG files:

- `icons/flags/hk.svg` - Hong Kong
- `icons/flags/us.svg` - United States
- `icons/flags/jp.svg` - Japan
- `icons/flags/sg.svg` - Singapore
- `icons/flags/kr.svg` - South Korea
- `icons/flags/tw.svg` - Taiwan
- `icons/flags/cn.svg` - China

Each SVG has been converted to a square drawing area by expanding the root
`viewBox` vertically and centering the original rectangular flag artwork. The
flag artwork itself is not scaled or redrawn.
